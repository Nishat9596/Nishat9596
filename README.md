### How I test an AI chatbot
| Area | What I check |
|---|---|
| Accuracy | Answers are correct and grounded in the source data, with no made-up facts |
| Conversation flow | Intents are recognised, context is kept across turns, fallbacks work |
| Consistency | Similar questions get consistent answers; no regressions after prompt or model changes |
| Safety | Harmful, biased or off-topic requests are handled correctly |
| Voice agents | Speech recognition with different accents and background noise, interruptions, response time |
| Edge cases | Typos, mixed languages, very long or empty inputs |
